# DualSight

> 并排看两版素材，一眼看出改了什么。

DualSight 是一个**本地优先的图片 / 视频对比工具**：把两个版本（原图 vs 修图、旧版 vs 新版、编码前 vs 编码后）放到同一个画布上，用并排、滑块、淡入淡出、闪烁四种方式对齐查看，并给出可量化的相似度指标。

纯前端实现（React + TypeScript + Canvas），既可当网页跑，也打包成 Windows 桌面应用。**所有文件都在浏览器本地解码，不会上传到任何服务器。**

## 核心功能

- **四种对比模式** — 并排 / 滑块 / 淡入淡出 / 闪烁，一键切换，切换时保留缩放、平移与视频播放进度。
- **图片 + 视频** — 图片（PNG / JPG / WebP / GIF / BMP / AVIF）与视频（MP4 / WebM / MOV / MKV）都支持，视频还可双路同步播放。
- **对齐比较** — 平移与缩放默认双图同步，也可在并排模式下分别独立操作。
- **同步放大镜** — 跟随鼠标的圆形放大镜，左右各取一半，在同一位置同时看两版像素。
- **光标取色** — 状态栏实时显示光标下的自然像素坐标，以及 A / B 两版的十六进制颜色值。
- **相似度分析** — 对两张图给出相似度、差异像素占比、PSNR、SSIM、MSE 四项指标。
- **画布背景** — 深色 / 浅色 / 棋盘格三种底色，方便检查透明通道与边缘差异。
- **中英双语 + 深浅主题** — 语言与主题各自独立持久化在本机。
- **示例素材** — 内置一组「原图 / 调色版」的图片与视频样例，无需准备文件即可试用。

## 四种对比模式

| 模式 | 交互方式 | 适用场景 |
|---|---|---|
| **并排对比** Side by Side | 画布固定 50/50 切分，左右各完整容纳整张媒体 | 整体构图、色调、排版的前后对比 |
| **滑块对比** Slider | 拖动中央分割线，同一位置切开 A / B | 细节修改、位置偏移的精确定位 |
| **淡入淡出** Fade | 滑动或自动播放 A ↔ B 的透明度混合 | 转场效果、整体风格差异 |
| **闪烁对比** Flicker | 按设定间隔在 A / B 之间硬切 | 微小差异、错位、伪影的「闪烁显现」 |

**并排模式下**，两个面板各占半屏；若关闭「同步平移和缩放」，可以单独缩放某一侧，适合两版尺寸或裁剪不一样的情况。

**淡入淡出与闪烁模式**在画布下方会出现专属控制条：Fade 提供混合程度滑块与自动循环播放；Flicker 提供 0.05–3 秒的间隔调节（滑块 + 数字输入），以及「显示 A / 显示 B」的定格按钮。

## 辅助工具：放大镜 / 取色 / 相似度

**同步放大镜**：鼠标移入媒体区域后出现一个圆形放大镜（默认 120px，可在 100–260px 间调节），按 **4 倍**放大。圆内以竖线一分为二 —— 左半取自 A，右半取自 B —— 所以两版在**同一像素位置**的差异会紧贴在一起呈现。

**光标取色**：底部状态栏持续跟随光标，输出自然像素坐标 `x, y`，并给出 A、B 两版在该点的 HEX 色值，可直接用来核对色差。

**相似度面板**：仅对**图片对**生效，先把两图缩放到最长边 256px 的缓冲区再逐像素比较，最终给出四项指标：

| 指标 | 含义 |
|---|---|
| 相似度 | 基于平均通道距离的感知相似度（0–100%），指数衰减模型 |
| 差异像素 | 通道平均差超过阈值（14/255）的像素占比 |
| PSNR | 峰值信噪比，越高越接近；超过 50 dB 显示为 ∞ |
| SSIM | 亮度通道的结构相似性（全局单窗口），越接近 1 越一致 |
| MSE | 均方误差，越小越接近 |

> 视频不参与相似度分析；跨域资源若未开启 CORS，画布像素不可读，指标会显示不可用。

## 快速开始

### 环境要求

- Node.js 18 或更高（推荐 20+）
- 任意现代浏览器（Chrome / Edge / Firefox / Safari）—— 开发预览用

### 安装与运行

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5180）
```

浏览器打开后：把两个文件**拖进画布**，或点击画布 / 侧边栏格子选择文件，即可开始对比。

### 构建与本地预览

```bash
npm run build      # 类型检查 + 构建 Web 产物与主进程
npm run preview    # 预览构建结果
```

`npm run build` 实际包含两步：`build:web`（`tsc --noEmit && vite build`，产物在 `dist/`）与 `build:electron`（编译主进程到 `dist-electron/`）。

### 可用脚本

| 命令 | 说明 |
|---|---|
| `npm run dev` | 启动 Vite 开发服务器（端口 5180） |
| `npm run build:web` | 类型检查并构建前端到 `dist/` |
| `npm run build:electron` | 编译 Electron 主进程到 `dist-electron/` |
| `npm run build` | 依次执行上面两项 |
| `npm run preview` | 预览已构建的前端产物 |
| `npm run dist` | 构建 + electron-builder 打包（Win x64） |
| `npm run dist:win` | 构建 + 走 `scripts/dist-win.mjs` 打包（**推荐**） |

## 打包为 Windows 应用

桌面壳使用 **Electron 44**，安装包由 **electron-builder 26 + NSIS** 生成向导式安装程序。

```bash
npm run dist:win
```

产物在 `release/`：

- `DualSight-Setup-<version>.exe` — 安装包（分发这个）
- `win-unpacked/DualSight.exe` — 免安装的解压版，可直接运行验证

> 注意：不要直接用 `npx electron-builder`。本机环境下 builder 解压工具链时的目录重命名会被拦截而报 `EPERM rename`，`dist:win` 通过预置工具链绕过了该问题。

**完整的打包细节** —— 图标替换（单一来源 `build/icon.ico`）、改版本号 / 应用名 / 输出目录 / 安装包文件名、窗口外观、NSIS 安装行为、验证清单 —— 都写在 **[PACKAGING.md](./PACKAGING.md)** 里。

## 操作速查表

| 操作 | 效果 |
|---|---|
| 拖入文件到画布 | 载入媒体（一次最多两个，按先后填入 A、B） |
| 拖入到侧边栏 A / B 格子 | 指定载入某个槽位 |
| 鼠标滚轮 | 以光标为中心缩放（1.15 倍/档，范围 10%–800%） |
| 按住左键拖动 | 平移画面（默认双图同步） |
| 拖动中央分割线 | 仅滑块模式：调整 A / B 分界 |
| 移动鼠标 | 状态栏显示坐标与 A / B 取色 |
| 顶栏 交换 A↔B | 交换两个槽位的媒体 |
| 顶栏 适应窗口 / 实际大小 | 重置缩放（1:1） |
| 顶栏 全屏 | 进入 / 退出全屏 |

**侧边栏选项**

- 同步平移和缩放 —— 关闭后，并排模式下两侧可独立操作
- 同步放大镜 —— 控制放大镜显隐
- 放大镜尺寸 —— 100–260px
- 背景 —— 深色 / 浅色 / 棋盘格

## 技术实现要点

| 方面 | 做法 |
|---|---|
| 前端框架 | React 18 + TypeScript，函数组件 + Hooks |
| 构建工具 | Vite 5，`base: './'` 以保证 `file://` 下资源路径正确 |
| 样式 | Tailwind CSS 3，色板通过 CSS 变量（RGB 通道三元组）驱动，深浅主题只换变量 |
| 缩放 / 平移 | 统一用 `ViewTransform { x, y, scale }` 描述，缩放以光标为锚点；屏幕坐标 → 舞台坐标 → 自然像素坐标三层换算 |
| 多模式合成 | A / B 两个图层在**所有模式下都保持挂载**，仅切换 `clipPath` / `opacity` / `visibility`，因此切换模式不会让视频重新从头播放 |
| 放大镜 | Canvas 绘制，按 devicePixelRatio 适配，避免 DOM 放大带来的模糊 |
| 相似度 | 两图缩放到最长边 256px 的离屏 Canvas，逐像素统计；SSIM 在亮度通道上做全局单窗口计算 |
| 取色 | 1×1 离屏 Canvas `drawImage` 采样，天然规避跨域污染并复用同一滤镜逻辑 |
| 视频同步 | A 为有声主轨、B 静音跟随；以 `requestAnimationFrame` 监测漂移，超过 0.25s 才纠偏，拖动进度条时对 B 的 seek 做 200ms 节流并带卡死看门狗，避免解码器被 seek 淹没导致画面冻结 |
| 桌面壳 | Electron 主进程 ESM，`contextIsolation: true` / `sandbox: true` / `nodeIntegration: false`，外部链接一律交给系统浏览器 |

## 隐私说明

- 选择或拖入的文件通过 `URL.createObjectURL` 在本地解码，**不上传、不联网、不写磁盘**。
- 应用不包含任何统计、埋点或远程请求；只有点击「示例素材」时才会访问外部 CDN 上的演示图片 / 视频。
- 语言与主题偏好保存在浏览器 / 应用本地的 `localStorage`（键名 `dualsight.lang`、`dualsight.theme`）。

## 常见问题

**相似度面板一直显示「相似度分析仅支持图片」**
两个槽位必须都是图片。只要其中一个是视频，相似度分析就不可用。

**相似度没有数值，或取色显示不可用**
图片来自网络且未返回 CORS 头时，画布会被标记为「污染」，无法读取像素。换成本地文件即可正常统计。

**构建后打开页面白屏 / 资源 404**
确认 `vite.config.ts` 中 `base: './'` 没有被改成 `'/'`，否则在 `file://` 协议下资源路径会失效。

**打包时报 `EPERM rename ... .tmp`**
这是本机环境拦截目录重命名导致的，请改用 `npm run dist:win`，详见 [PACKAGING.md](./PACKAGING.md) 第 4 节。

**换了图标但快捷方式还是旧图标**
Windows 按 exe 路径缓存图标。`build/installer.nsh` 已在安装 / 卸载时执行 `ie4uinit` 刷新缓存；手动排查可重启资源管理器或注销。
